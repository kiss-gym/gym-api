0. Task: Initial
-----------------------------------
I'd like to make an draft architecture for gym training (freeware),
where each training session, a sequence of exercise (exercise:
picture or foto, start / end time, automatic label,
ad-hoc-defined custom name/value property list) can be inherited by the next training sequence
(no explicit training plans).

Workflow, Logic : It must be easy to access / edit / delete existing sessions,
and inherit the latest to create a new one (current).

My cloud platform would be Azure Container Apps, the full app logic RESTful (ASP.NET Core C# with OpenAPI aka Swagger.

For database and Auth-engine I'd use supabase. The primary client is a React Native Expo Android app, the secondary is React /next.js.

Features coming next: Calender planning and reminders.

I'd like to use DDD (partially).
I see the following Bounded Contexts:
- Current Session Tracking (core subdomain),
- Session Management (important supporting subdomain),
- User management (generic subdomain),
- Exercise Library (supporting subdomain).

We begun with Training Tracking (core subdomain).
The use case is:
- Create Session,
- Add/Start exercise (each exercise finishes previous and can be autofinished),
- Remove exercise,
- Finish session.

1. Task:Exercise Sets
--------------------
The exercise API needs extension:
Each set has auto-numerated order number, "finished" bool property, weight decimal property (nullable),
and numeric repetitions (number) property (nullable). If all sets "finished", the exercise finishes as well.
If exercise  set to finish, all the containing sets marked as finished.
No set can be added to the finished exercise. 

Endpoints extensions:

// adds a new set
POST /api/sessions/{sessionId}/exercises/{exerciseId}/sets
Body: { weight?: number, repetitions? integer }
→ 201 ExerciseSet
→ Server auto-assigns setNumber = last setNumber + 1

// updates set (finish, update weight/repetitions)
PATCH /api/sessions/{sessionId}/exercises/{exerciseId}/sets/{setId}
Body: { isFinished?: boolean, weight?: number, repetitions?: integer }
→ 200 ExerciseSet

// removes a set
DELETE /api/sessions/{sessionId}/exercises/{exerciseId}/sets/{setId}
→ 204 No Content
